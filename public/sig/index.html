AKAY email signatures

Find your name, press Copy signature, then paste it into Gmail. Takes about a minute.

1. Press Copy signature under your name below.
2. In Gmail on a computer: ⚙ → See all settings → General → scroll to Signature → Create new → name it "AKAY" → click in the box and paste (Ctrl+V / Cmd+V).
3. Just below, set For new emails use and On reply/forward use to "AKAY".
4. Scroll to the bottom and press Save changes. Send yourself a test email.
If the copy button does not work in your browser, open the signature link, select all (Ctrl+A / Cmd+A), copy, and paste the same way. Gmail signatures are set on a computer, not in the phone app.
