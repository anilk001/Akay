## What the numbers mean

The supplier quotes **one price per case** (`FOB Jakarta` column), and both lists give
units-per-case, so every row has a case price and a derived unit price:

```
Buy Price            supplier FOB price for one case
Sell Price Per Case  Buy Price × 1.05          (the 5% margin)
Sell Price Per Unit  Sell Price Per Case ÷ PCS/Case
Price Per Unit & Case  "USD 43.03/case (12pk) · USD 3.59/unit"  ← what the portal card renders
```

Unit figures on cheap sachet packs keep 3–4 decimals so that
`case = unit × pack` stays exact — the catalogue derives its per-unit sort key
from this string.

Sum of one case of every line: **USD 181,649.71 buy → USD 190,732.45 sell**
(reference figure only — no quantities were quoted). Unit prices run USD 0.17–20.47.

## Assumptions — confirm these before publishing

1. **Currency is USD** — confirmed by AK on 26 Aug 2026. Neither list states one; both say
   only "FOB Jakarta".
2. **5% is applied as a markup on cost** (`cost × 1.05`), not as a 5% gross margin on the
   sell price (`cost ÷ 0.95`). On a USD 100 case that is 105.00 rather than 105.26.
3. **No stock quantities were quoted**, so `Stock Cases` is blank and `Stock Display` is
   `Enquire` for every row.
4. **Category is `Toiletries` for all 788 rows.** The catalogue has no cosmetics or
   make-up category; the supplier's own category (Women Skin Care, Makeup, Hair Colour…)
   is preserved in `Supplier Category`.
5. **`Public Listing` is `No` on every row.** Nothing reaches offers.akay.ie until someone
   reviews the flagged rows and flips it to `Yes`.
6. **`Offer Expiry` = 2026-09-25** on every row, per the 30-day auto-expiry rule.

## Review flags (499 rows carry at least one)

The `Review` column names the reason; nothing was silently guessed.

| Rows | Flag | What to do |
|---|---|---|
| 423 | `no unit size on the supplier line` | The supplier's description carries no ml/g (e.g. "GAR 2 STEP PW MASK B5 GINSENG", or Ellips formats given only as "Jar"/"Blister"). `Public Spec` falls back to the case count. Add the size before publishing, or the card shows a pack count with no volume. |
| 151 | `name codes` | The public name still contains a supplier shorthand that could not be expanded safely (e.g. `NC`, `TWC`, `OA`, `SRP`). The code is named in the flag. |
| 32 | `bundle/value set` | Names like `VS … SHP 170ML + FR MASK` or `BOGOF …` price a multi-item pack. The size taken is the first one in the name; confirm what a case actually contains. |
| 22 | `duplicate line in the supplier list (2x)` | Same brand, name, pack and price on two lines with different distributor codes. Merge before import or the catalogue gets twin cards. |

Product names were expanded from the supplier's SKU shorthand only where the meaning is
unambiguous (`SHP`→Shampoo, `CDR`→Conditioner, `REV`→Revitalift, `ELS`→Elseve, `TR5`→Total
Repair 5, `MCLR`→Micellar…). Division and market codes that say nothing about the product
(`DEX`, `MU`, `AS`, `EB`, `EBT`, `PCR`, `V2`…) were dropped. The untouched supplier text is
kept in `Product Name`, so nothing is lost.

## Importing

Airtable → `Akay Offers` base → `Offers` table → grid view → right-click → *Import data* →
CSV. Column names match the base 1:1. `Source List`, `Source Row`, `Review` and
`Notes` are working columns — map them to internal fields or drop them at import; they
must never be added to the public field allowlist in `src/data/airtable.mjs`.

Supplier identity, buy price and margin stay internal — the catalogue only ever requests
the public-safe fields.

## Re-running

```bash
python3 .claude/skills/price-list-intake/intake_surya_graha.py \
  --loreal LOREAL_GARNIER_1.xlsx --ellips ELLIPS_1.xlsx \
  --out imports/2026-08-26-surya-graha \
  --margin 5 --expiry-days 30 --currency USD --today 2026-08-26 \
  --drop-sell-through
```

`--today` fixes the expiry base date so a re-run reproduces this file exactly; omit it to
expire 30 days from the day you run it. Drop `--drop-sell-through` to keep the 244
sell-through lines in the import, flagged rather than removed.
