# Vendored third-party skills

These design skills are vendored from open-source repos (all MIT-licensed;
LICENSE files included alongside each). To update one, re-copy its SKILL.md
from the source repo.

| Skill | Source |
|---|---|
| emil-design-eng | https://github.com/emilkowalski/skills |
| web-design-guidelines | https://github.com/vercel-labs/agent-skills |
| brandkit | https://github.com/leonxlnx/taste-skill |
| image-to-code | https://github.com/leonxlnx/taste-skill (skills/image-to-code-skill) |
| extract-design-system | https://github.com/arvindrk/extract-design-system |

UI/UX Pro Max is not vendored — it is installed as a plugin via
`.claude/settings.json` (`ui-ux-pro-max@ui-ux-pro-max-skill`).
